# Online Learning App

This is a simple **Online Learning App** created using HTML, CSS, and JavaScript.

---

##  Project Overview

- This web app helps people to **sign in** and **log in**.
- It is the first step to building a full learning platform.
- The design is basic and easy to use.

---

## Features

- **Sign In Page** – allows new users to register.
- **Login Page** – lets users sign in if they already have an account.
- **Simple Interface** – easy to understand and use.
- **Responsive Design** – works on both desktops and mobile devices.

---

## How to Use

1. Clone the repository : git clone https://github.com/challabala/Online-Learning-App.git
2. cd Online-Learning-App
3. Open *index.html* in your web browser.
